    Catatan: apa itu syntax
    

    
    Pengertian syntax
    
    
    Syntax adalah aturan penulisan sebuah bahasa: urutan, tanda baca, dan bentuk yang harus diikuti supaya komputer bisa membaca kodenya. Mirip tata bahasa sehari-hari. Kalimat yang urutannya salah masih bisa ditebak manusia, tetapi komputer butuh aturan yang pasti.
    

    
    Syntax pada HTML
    
    
    HTML singkatan dari HyperText Markup Language. Markup language artinya bahasa penanda: tugasnya memberi tanda pada teks, misalnya “ini judul”, “ini paragraf”, atau “ini tautan”. HTML bukan bahasa pemrograman karena tidak punya logika seperti perhitungan atau percabangan. Syntax-nya berupa tag yang ditulis di dalam tanda < >.
    

    
    Bagian-bagian syntax HTML
    
    
      
      
    • Tag: nama di dalam < >. Tag pembuka <p>, tag penutup </p>.
      • 
      
    • Elemen: tag pembuka, isi, dan tag penutup digabung. Contoh <p>Halo</p>.
      • 
      
    • Isi: teks atau elemen lain di antara tag pembuka dan tag penutup.
      • 
      
    • Atribut: pengaturan tambahan di tag pembuka, ditulis nama="nilai". Contoh <a href="https://contoh.com">: href nama atributnya, alamatnya nilainya.
      • 
      
    • Deklarasi: <!DOCTYPE html> bukan tag biasa, melainkan instruksi agar browser memakai standar HTML5.
      • 
      
    • Komentar: <!-- catatan -->. Tidak tampil di halaman dan tidak boleh bersarang.
      • 
      
    • Entitas karakter: kode untuk karakter khusus. &lt; untuk tanda <, &gt; untuk >, &amp; untuk &, &quot; untuk tanda kutip, &nbsp; untuk spasi yang tidak terputus, dan &copy; untuk ©.
      • 
    
    

    
    Aturan syntax HTML
    
    
      
      
    1. Tag diawali tanda < dan diakhiri >.
      2. 
      
    2. Tag penutup memakai garis miring: </p>.
      3. 
      
    3. Nama tag dan nama atribut tidak membedakan huruf besar kecil (<P> sama dengan <p>), tetapi tulis dengan huruf kecil. Nilai atribut seperti nama file bisa membedakan huruf besar kecil.
      4. 
      
    4. Beri tanda kutip pada nilai atribut: href="halaman.html".
      5. 
      
    5. Atribut hanya ditulis di tag pembuka, dipisah spasi: <img src="foto.jpg" alt="Foto">.
      6. 
      
    6. Satu atribut tidak boleh ditulis dua kali dalam satu tag.
      7. 
      
    7. Sebagian atribut boleh tanpa nilai, misalnya <input disabled>.
      8. 
      
    8. Elemen bersarang harus rapi dan tidak boleh bertumpang: <b><i>teks</i></b>.
      9. 
      
    9. Spasi dan enter di kode tidak berpengaruh: beberapa spasi atau baris baru ditampilkan sebagai satu spasi. Untuk pindah baris pakai <br>, untuk paragraf pakai <p>.
      10. 
      
    10. Karakter < dan & yang mau ditampilkan sebagai teks ditulis sebagai entitas.

    Syntax error di HTML
    
    
    Di bahasa pemrograman, syntax yang salah biasanya membuat program berhenti dan menampilkan pesan error. HTML tidak begitu: browser mencoba memperbaikinya sendiri dan tetap menampilkan halaman. Akibatnya tidak ada pesan, tetapi hasilnya bisa berbeda dari maksudmu. Karena itu syntax HTML perlu ditulis dengan teliti. Contohnya ada di catatan kenapa tag harus ditutup di bawah.
    

    
    Struktur dokumen minimal
    

    <!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Judul halaman</title>
</head>
<body>
  <h1>Judul</h1>
  <p>Paragraf.</p>
</body>
</html>
    
    
    lang="id" memberi tahu bahasa halaman. <meta charset="UTF-8"> menentukan set karakter supaya huruf dan simbol tampil benar.

    Catatan: kenapa tag harus ditutup
    

    
    1. Anatomi sebuah elemen
    
    
    Contoh <p>Halo</p> terdiri dari tag pembuka <p>, isi Halo, dan tag penutup </p>. Ketiganya digabung disebut elemen. Tag penutup sama dengan tag pembuka, hanya ditambah garis miring (/).
    

    
    2. Kenapa harus ditutup
    
    
    Tag pembuka berarti “mulai dari sini jadi paragraf”. Tag penutup berarti “sampai sini saja”. Tanpa penutup, browser harus menebak di mana elemen itu berhenti.
    
    
    HTML itu pemaaf: kalau ada yang kurang, browser memperbaikinya diam-diam dan tidak menampilkan pesan error. Itu enak buat pengunjung, tapi berbahaya buat penulis kode. Kesalahan kecil baru ketahuan setelah tampilan berantakan, dan tebakan browser belum tentu sama dengan maksudmu.
    

    
    3. Kenapa </p> yang dilupakan masih bisa jalan
    
    
    Aturan HTML mengizinkan </p> dihilangkan kalau setelahnya langsung ada elemen seperti p lain, heading, div, ul, ol, atau table, atau kalau induknya sudah berakhir. Browser lalu menutup p itu sendiri.
    

    <p>Paragraf pertama
<p>Paragraf kedua
    
    
    Kalau setelahnya bukan salah satu elemen itu, p tidak berhenti dan terus menelan isi sesudahnya. Karena pengecualiannya panjang, kebiasaan terbaik adalah selalu menulis </p>.
    
    

    
    4. Kenapa <h6> harus ditutup dengan </h6>
    
    
    Berbeda dengan p, tag penutup heading (h1 sampai h6) tidak boleh dihilangkan. Kalau lupa </h6>, elemen sesudahnya ikut masuk ke dalam h6.
    

    <h6>Judul kecil
<p>Paragraf ini ikut masuk ke dalam h6</p>
    
    
    Hasilnya mungkin masih terlihat “jalan”, tetapi paragraf itu tampil tebal dan kecil mengikuti gaya h6. Pembaca layar dan mesin pencari juga menganggapnya bagian dari judul. Tampilannya tidak error, tetapi strukturnya salah.
    
    
    

    
    5. Elemen kosong tidak perlu ditutup
    
    
    Elemen yang tidak membungkus isi, seperti <br>, <hr>, <img>, <input>, <meta>, dan <link>, memang tidak punya tag penutup. Jangan menulis </br> atau </img>.
    
    

    
    6. Tutup dari yang paling dalam
    
    
    Elemen bersarang seperti kotak di dalam kotak: yang dibuka terakhir ditutup pertama.
    

    Benar:  <b><i>teks</i></b>
Salah:  <b><i>teks</b></i>
    

    
    7. Huruf kecil dan indentasi
    
    
    <P> dan <p> dianggap sama oleh browser, tetapi tulis semuanya dengan huruf kecil. Beri indentasi pada isi elemen supaya pasangan tag pembuka dan penutupnya mudah dicari.
    

    
    8. Cara mengecek
    
    
    Browser tidak akan memberi tahu kalau ada tag yang lupa ditutup. Untuk memeriksanya, tempelkan kode ke validator HTML milik W3C (validator.w3.org). Di halaman ini, daftar “Perubahan yang dibuat” juga menandai tag yang tidak ditutup.
    

    
    Aturan praktis
    
    
    Selalu tutup semua tag yang punya isi. Pengecualiannya hanya elemen kosong.
